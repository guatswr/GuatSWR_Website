# 公开内容与搜索引擎

2026-10-19：新版公开页正文由 Nuxt SSR 输出。无需运行浏览器 JavaScript 即可读取首页、活动正文、成员、群史、事件及公开日志。每个页面有独立标题、描述、canonical、OG/Twitter 信息；文章和有明确时间的活动另外输出结构化数据。SSR 不等于允许收录：当前预览仍统一禁止索引。

## 索引与输出约定

- `next.guatswr.top` 保持 `noindex, nofollow`、robots 禁止抓取，sitemap 模块关闭。即使意外设置 `NUXT_SITE_INDEXABLE=true`，默认预览路由头仍禁止索引。
- 唯一 sitemap 所有者是 `@nuxtjs/sitemap`，数据来自封闭的 `/api/__sitemap__/urls`。只包含明确的公开静态路由和已发布活动详情；不包含登录、后台、内部验证入口及 `/events` 跳转。
- 站点链接只使用配置并验证的可信 origin，不采信请求的 Host/X-Forwarded-Host。活动封面只接受安全站内路径，否则使用本地 OG 回退图。
- `/rss.xml` 发布最近 20 篇公开活动的元数据，不输出原始 Markdown、私人字段或报名内容。XML 字符经过校验与转义，描述另外转义 HTML 语义。
- 活动文章的 SQLite `created_at` 解释为 UTC；事件填写的无时区日程解释为北京时间。未知日程不虚构开始时间，不把报名截止时间当作开始时间。
- sitemap 分页有总量、总耗时和一致性边界。数据源异常、分页不完整及超过 5000 条均返回 503，不伪造成功的空站点地图。RSS 元数据超限同样失败关闭。
