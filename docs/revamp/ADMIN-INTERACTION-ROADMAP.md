# 后台交互改造节点表

本轮明确需求：按年月维护群史、快速授权 Bot、查看已保存 Token、日志脱敏。采用逐节点交付，每个节点包含实现、错误状态、权限边界和实际浏览器验收；不以一次替换所有页面为目标。

## 参考与采用方式

- [Ant Design Table](https://ant.design/components/table/)：把查找、筛选、分页和操作反馈放进列表工作流；筛选变化时回到第一页。
- [SAP Fiori Flexible Column Layout](https://learning.sap.com/courses/developing-an-sap-fiori-elements-app-based-on-a-cap-odata-v4-service/configuring-the-flexible-column-layout_b5066855-aa7c-4943-a64b-64050ccfea75)：保留列表与详情上下文，避免编辑后反复寻找原记录。后续统一侧栏编辑器时采用这一原则。
- [GitLab CI/CD Variables](https://docs.gitlab.com/ci/variables/)：区分密钥是否允许查看、默认可见性和日志遮蔽。本站按用户要求提供站长按需查看；列表不直接返回 Token。
- 本项目继续使用现有 Vue、Element Plus 和后台样式体系，不为了借鉴交互而引入 React 或另一套组件库。

## Token 的兼容和运维约定

1. 主库新增显式迁移 main6，新增独立 `bot_credential_secrets` 表；旧迁移不修改。main4/5 在未配置新功能时继续兼容运行。
2. 独立 `BOT_CREDENTIAL_ENCRYPTION_KEY` 为 32 字节随机密钥的 64 位十六进制表示。密钥放在数据库和公开资源目录之外的受控配置中，不能复用 JWT 或出站 Webhook Token。配置了密钥但未升级数据库时拒绝启动，避免误认为已加密保存。
3. 鉴权继续使用 SHA-256 摘要；可恢复副本使用 AES-256-GCM，凭据 ID 绑定为 AAD。站长查看时重新检查当前角色、记录仅含凭据 ID 的审计，并经 BFF 的 Origin/CSRF 校验。
4. 默认遮蔽。查看结果只保存在当前组件内存，60 秒、页面失焦、切后台、登出或离开时清除；不放进查询缓存、localStorage、URL 或列表响应。
5. 历史上只保存摘要的 Token 无法反向恢复。保留旧凭据继续可用，由站长按需创建替代凭据并在插件切换后撤销旧项；不会自动失效旧 Token。
6. 加密密钥需单独安全备份。更换或丢失密钥会影响已有加密副本的查看；当前阶段没有自动重加密工具。已撤销凭据删除加密副本。
7. 日志新写入前过滤 Bot Token、JWT、Bearer 及带标签的密码/Token；管理端读取旧日志再过滤一次。诊断日志继续只写入固定字段和错误代码。

## Bot 功能集中管理（后续归类）

- 统一页面 `/admin/bot`，分凭据与权限、群成员同步、成员资料、通知投递四区；当前分区和成员目标保存在查询参数中，可刷新和分享。
- 住民管理移除 Bot 配置表单，保留跳转入口；网站内容仍由住民管理维护，Bot 专属 QQ 关联/跟随/核验在 Bot 页维护。
- 普通管理员可处理成员资料；凭据、群同步配置和投递重试只开放给站长，服务端权限不放宽。
- 后续资料私信直接指向新页面；旧待办链接保留重定向。操作日志中的 Bot 相关动作也提供对应区域入口。
- 状态：已完成（本地）。前端 755 项、共享包 79 项、相关后端 11 项通过；实际 BFF 和浏览器流程各 1 项通过，覆盖旧链接重定向、成员资料往返、通知重试、Token 弹窗和普通管理员权限。四个分区和手机布局已用本地原库复核。

本轮验证细节：构建并发时一项既有限流测试触及 5 秒超时，限制测试并发后全量通过，未放宽断言或超时。浏览器测试改为等待快照应用成功后再导航，并兼容登录返回路径；角色切换测试从新的登录页开始，最终流程包含普通管理员旧链接重定向及站长接口拒绝访问。
