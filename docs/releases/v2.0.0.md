# v2.0.0

前后端现代化与后端迁移的正式代码版本。后端必需工程节点 BM00–35 已完成，发布分支合入 main，保留逐里程碑提交历史。

## 主要变化

- 前端采用 Nuxt 4/Vue 3，共享契约、固定 BFF 路由及服务端会话，公开数据与管理投影分离。
- 后端使用 Node 24、Express 5 和严格 TypeScript 业务分层；保留 CommonJS 平台桥、sqlite3 与参数化 SQL。
- 主库和审计库采用独立版本迁移账本，当前为 main 3 / audit 2；启动不自动迁移或创建管理员。
- 用户级令牌撤销、现查权限、可靠安全审计、游客草稿证明和上传资源边界已实现。
- 文件发布支持独占准备、事务内最终引用复核、崩溃恢复与可恢复隔离；备份具有完整验包、恢复及最后有效恢复点保护。
- 生产镜像以非 root 用户运行；配套只读回退启动器、迁移/恢复手册及发布检查表。

## 验证

- 后端 Windows 2013 项、Linux 2014 项通过；71 个 API 操作、11 组 wire 输入模型及真实 Nuxt BFF 验证通过。
- 前端 730 项、shared 79 项、工具 103 项，以及类型、lint 和依赖安全门禁通过。
- 历史副本中主库 233 行、审计 1143 行保持；新旧版本 14 组读取和 523 个资源文件一致。
- 受控停写恢复演练 RPO 为 0、约 70.5 MB 包的 RTO 为 3.924 秒；两轮同负载性能未触发既定阻断条件。这些指标不代表生产 SLA。
- 冻结代码候选 `8dd71383a8b8776f47c4bee0477e20a5c1caf6ce` 及文档收口 `11d1d65e408d4a31e2a50692694d4f949974fdf4` 的四项远程门禁全部通过；本标签还须通过精确 main 提交门禁后才生成 Release。

## 使用与上线边界

本次发布 Git 标签和 GitHub Release，**暂不部署生产**；正式数据库、资源和流量未切换。部署须另行按 [发布清单](https://github.com/guatswr/GuatSWR_Website/blob/v2.0.0/docs/backend-modernization/RELEASE-CHECKLIST.md)核对实际环境、前端独立门禁和窗口授权。

已有库必须显式 adopt/upgrade，不得覆盖已有数据目录。main 3 / audit 2 的最低只读回退基线为 `b343784`，须配套当前 `read-only-server.cjs` 和新恢复工具；已有新写入时不得覆盖旧快照。BFF 草稿归属仍是单进程内存状态，部署前须排空或明确处理重启影响。

驱动替换、Drizzle 查询和 GCM 凭据格式按既定计划延期。`v2.0.0` 是仓库发行版本；冻结的 `/api/version` 响应保持原有 `4.0` 契约。
