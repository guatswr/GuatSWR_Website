# PG-03 BFF PostgreSQL 状态修复证据

日期：2026-11-08。状态：CODE_VERIFIED（本地隔离验证；生产未验收）。

旧版证据仅依赖模拟 pg，并未验证 PostgreSQL 事务；其跨实例锁与故障保证结论撤回，以本文件和 release 回归为准。

## 实现

- `postgres-state.ts` 为每个私有 URL 共享最多 4 条连接，等待队列最多 128，连接超时 1 秒、SQL 5 秒、锁 1 秒、事务总期限 12 秒。close 拒绝新操作，等待并取消残余任务，最后一个命名空间关闭共享池。
- 对不存在的键也先取得事务 advisory lock；SELECT FOR UPDATE 保护已有行。容量检查有独立锁；批量撤销与过期清理使用命名空间独占锁，扫描游标持续前进。
- identity 刷新使用 compare-and-swap；注销发生在上游 /me 返回与刷新提交之间时，旧验证不能重建会话。
- AES-256-GCM 保持原 SHA-256 purpose/namespace 密钥派生格式和记录 ID AAD；损坏密文返回 503 并保留原记录供调查。这里没有 HKDF，也不声称数据库管理员无法控制应用环境。
- 草稿首次 intent 发行跨实例串行；不保存原始 cookie。提交锁使用随机 owner token 和默认 30 秒租约，进程重启后可过期恢复；后端持久化幂等回执处理未知提交结果。状态写入失败向调用者传播。
- BFF_DATABASE_DRIVER 优先于 DATABASE_DRIVER；postgres 缺少私有 URL 或配置非法时拒绝启动存储，不回退 SQLite。

## 可复现验证

`pnpm test:release` 在唯一的、loopback Docker PostgreSQL 18.6 实例中运行真实并发注销、跨实例发行和重启租约、缺失键竞争、容量限制、跨页清理及损坏密文测试。`pnpm --filter @guatswr/web test` 检查配置和既有前端行为；该套单元测试不作为数据库事务证据。

BFF 状态可共享不代表图片目录、限流、缓存和后台任务已支持多实例。首次生产切换仍限制为单 backend / 单 BFF。
