# ASSET-02 复核：索引正向命中与权威来源回退

- 复核日期：2026-11-06
- 正确性修复：专项回归通过；全量回归结果见工作区 review 日志。
- 性能目标：尚未完成全量写路径同步，不能宣称全量扫描已退役或写事务恒为 O(1)。

## 已复现的问题

此前的定向 LIKE 探测只检查 20 个候选，会遗漏后续真实引用；使用原文件完整文件名探测还会遗漏不同扩展名的缩略图，以及百分号编码的 URL。

代码中只有报名头像调用 `syncEntityAssetReferences`；其他资产来源尚未在每个写事务中同步索引。影子表存在或非空，均不能证明一次索引未命中代表资源没有引用。

## 本次修复

`isAnyAssetTargetReferenced` 保留本次操作引用和影子索引的正向命中快速路径；未命中时，在当前事务内读取全部权威来源并按资源家族比较。无法解析的本地引用使查询保守返回保留。

`rebuildAssetReferences` 的权威来源读取与索引替换现在置于同一写事务，避免读完后其他写入提交、再用旧快照覆盖索引。

报名头像集成测试补齐真实 publicRoot，并检查索引保存规范化绝对路径和 `incomplete=0`，避免原测试依赖缺失目录时生成的异常引用。

## 验证与后续条件

新增回归覆盖超过 20 个文件名碰撞、不同图片扩展名的同族引用以及百分号编码路径；原有报名、取消报名与共享头像引用测试使用真实存储目录验证。

完成全部八类来源的事务内索引同步、迁移回填和一致性校验之前，必须保留权威扫描回退。旧版本“全量扫描已退役”“剩余风险无”及相关 O(1) 性能结论已撤回；性能数据需在当前安全实现上重新测量。
